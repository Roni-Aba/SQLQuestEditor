# SQL Quest Editor

Der SQL Quest Editor ist ein Django-basiertes Tool zum Erstellen und Bearbeiten von Leveln für SQL Spell Quest.

## Dependencies
Für diesen Editor wird Python benötigt. Dies erfolgt via:
- https://www.python.org/downloads/

Zudem wird Django benötigt dies erfolgt via: 
macos: 
    - python -m pip install Django 
    - python3 -m pip install Django 

windows:
    - py -m pip install Django
## Projekt starten

```bash
cd backend
python manage.py runserver
